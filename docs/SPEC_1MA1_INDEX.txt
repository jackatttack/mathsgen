EDEXCEL GCSE (9-1) MATHEMATICS 1MA1 - CONTENT CODE INDEX
Source: Pearson Edexcel 1MA1 specification, Issue 2 (June 2015)
https://qualifications.pearson.com/content/dam/pdf/GCSE/mathematics/2015/specification-and-sample-assesment/gcse-maths-2015-specification.pdf

Purpose: reference codes for tagging mathsgen skills. Labels are short
paraphrases, not specification text; read the PDF for exact wording.

Tier key
  F    in the Foundation list (Higher also assessed on it)
  F+H  in both lists; the Higher list extends it (extension after "H:")
  H    Higher only
Caveat: the extracted PDF loses underline styling, so "harder Foundation"
content is not distinguished from basic Foundation content.

Year groups are NOT in the specification. The spec assumes the DfE KS3
programme of study. Any year tagging in mathsgen is our own layer.
